ℹ️ Âge du public

Indiquez la tranche d'âge à laquelle s'adresse l'évènement (de 0 à 18 ans).

  • Âge minimum : âge à partir duquel l'évènement est adapté.
  • Âge maximum : âge jusqu'auquel l'évènement reste adapté.

Laissez les deux champs vides pour un évènement tout public.

ℹ️ Tags

Les tags permettent de décrire l'évènement et d'en faciliter la recherche.

  • Exemple de tag : enfant, cirque, rock, etc.
  • Conseil : utilisez des tags pertinents, précis et cours.

Vous pouvez ajouter jusqu'à 4 tags.

ℹ️ Date de fin

Indiquez la date de fin de l'évènement si celui-ci s'étend sur plusieurs jours. Un évènement individuel sur chaque jour sera créé automatiquement.

Note : lorsque vous voudrez supprimer ou éditer l'évènement, il faudra ensuite le faire pour chaque jour séparément.

ℹ️ Catégories

Chaque évènement est associé à une ou plusieurs catégories définies ici.

Veuillez en sélectionner au moins une.

Note : chaque catégorie est associée à une couleur, qui servira de légende pour faciliter la recherche d'évènements.

ℹ️ Où ?

Filtrez les évènements par zone géographique, déterminée à partir du code postal du lieu.

  • Rabas/Couf : évènements situés dans le 81800.
  • Salvagnac : évènements situés dans le 81630.
  • Ailleurs : évènements situés dans les autres communes.

ℹ️ Aide

Navigation :

Parcourez ici les différents évènements disponibles.

Chaque évènement peut être classé en plusieurs catégories (concert, spectacle, exposition, etc.) et un code couleur fait office de légende.

Utilisez les boutons pour choisir le mode d'affichage des évènements :

  • view_agendaListe : les évènements à venir, regroupés par période.
  • calendar_monthAgenda : les évènements sur un calendrier mensuel.

Cliquez sur un évènement pour en voir les détails.

Lorsque la carte de l'évènement est ouverte, des boutons sont disponibles en bas pour partager ou éditer/supprimer vos évènements.

Filtre :

Utilisez les boutons de la barre d'outil pour filtrer par catégorie.

Ouvrez « Plus de filtres » pour affiner la recherche par zone, âge du public, prix ou mot-clé.

Lorsqu'au moins un filtre est activé, un bouton Reset apparaît pour permettre de réinitialiser les filtres.
